# 작업 문서 작성 규칙

- **적용 범위:** 이 폴더와 하위 폴더의 작업 문서
- **작성 전 확인:** [작업 문서 안내](README.md)의 작성 스타일·상태 모델·완료 기준
- **문서 작성·수정:** [문서 작성 스타일](README.md#문서-작성-스타일) 준수
- **작업 관리:** `active/`에 작업 목록과 진행 상황 기록, 완료 조건 충족 후 `completed/`로 이동
- **단독 사용:** 이 폴더 내부의 안내와 템플릿을 기준으로 작성, 관련 문서는 프로젝트에 존재하는 경우에만 연결
- **외부 검토 기록:** 검토 산출물(JSON 결과, `metrics.jsonl`)은 `active/reviews/<TASK-ID>/`에 둡니다. Task 문서의 경로와 형식은 바꾸지 않습니다 — `active/T003-....md`는 파일 그대로 두고 검토 기록만 형제 디렉터리에 쌓습니다. Task를 `completed/`로 옮길 때 `reviews/<TASK-ID>/`도 함께 옮깁니다
