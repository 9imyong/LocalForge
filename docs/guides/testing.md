# 테스트 안내

## 테스트 원칙

- 동작에 가장 가까운 낮은 비용의 테스트를 우선합니다.
- 외부 계약은 계약 테스트로 검증합니다.
- 오류, 경계값, 권한, 중복 요청 같은 실패 경로를 포함합니다.
- 불안정한 테스트를 무시하지 않고 원인과 소유자를 기록합니다.

## 테스트 종류와 명령

| 종류 | 목적 | 실행 명령 |
|---|---|---|
| 단위 | 작은 업무 규칙 검증 | 작성 필요 |
| 통합 | 구성 요소와 저장소 연동 검증 | 작성 필요 |
| 계약 | API와 이벤트 호환성 검증 | 작성 필요 |
| 종단 간 | 핵심 사용자 흐름 검증 | 작성 필요 |

## 완료 기준

변경 요청에는 실행한 검증, 결과, 실행하지 못한 항목과 이유를 기록합니다.
