# 릴리스 안내

## 릴리스 전

- [ ] 릴리스 범위와 버전을 확정합니다.
- [ ] 자동화 테스트와 계약 검증을 통과합니다.
- [ ] 데이터 마이그레이션과 하위 호환성을 확인합니다.
- [ ] 사용자 및 운영 문서를 갱신합니다.
- [ ] 관측 지표와 되돌리기 절차를 확인합니다.

## 릴리스

실제 빌드, 서명, 배포, 승인 명령과 담당자를 작성합니다.

## 릴리스 후

- [ ] 상태 확인과 핵심 사용자 흐름을 검증합니다.
- [ ] 오류율, 지연 시간, 자원 사용량을 관찰합니다.
- [ ] 문제 발생 시 되돌리기 절차를 실행합니다. 절차는 이 문서에 기록합니다.
