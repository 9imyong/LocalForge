## 배포 전 점검

- [ ] 변경 범위와 위험을 확인합니다.
- [ ] 테스트와 계약 검증을 통과합니다.
- [ ] 데이터 변경의 호환성을 확인합니다.
- [ ] 대시보드와 경보가 준비되어 있습니다.
- [ ] 되돌리기 가능한 버전과 절차를 확인합니다.

## 배포 절차

실제 환경에 맞는 명령, 단계별 기대 결과, 중단 조건을 작성합니다.

## 배포 검증

상태 확인, 핵심 사용자 흐름, 오류율과 지연 시간 기준을 작성합니다.

## 되돌리기

되돌리기 판단 기준, 명령, 데이터 호환성, 완료 확인 방법을 작성합니다.
