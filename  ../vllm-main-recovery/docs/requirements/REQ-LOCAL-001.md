# 로컬 LLM 서빙 실험 환경

## 목적과 범위

- 목적: 로컬 GPU에서 언어 모델을 실행하고 API 응답·스트리밍·성능을 반복 검증하는 개발 환경 확보
- 주요 사용자: 로컬 모델을 실험하거나 다른 서비스와 연동하는 개발자
- 1차 범위: 단일 호스트, 단일 모델, 텍스트 대화, 명령행 클라이언트
- 후속 범위: 웹 UI, 서비스 게이트웨이, 여러 모델, RAG, 도구 호출, 멀티모달
- 제외: vLLM 추론 엔진 자체 재구현, 모델 학습
- 확인된 환경·용도: 사용자 제공 3090 1개, 한국어 대화 및 코딩; RTX 3090 기본 24GB 구성으로 잠정 해석

## 요구사항과 인수 조건

| ID | 요구사항 | 인수 조건 |
|---|---|---|
| LOCAL-01 | 반복 가능한 실행·종료 | 이미지와 모델 revision 고정, 같은 설정으로 재기동 3회 후 추론 성공 |
| LOCAL-02 | 텍스트 대화 API | 모델 조회 및 한국어·영어 대화 샘플 20건의 정상 응답 확인 |
| LOCAL-03 | 스트리밍 | 완료 전 내용 청크 수신, 종료 신호 확인, 연결 취소 후 후속 요청 성공 |
| LOCAL-04 | 오류 처리 | 잘못된 모델·입력 길이 초과·인증 실패의 오류 응답 확인, 서버 생존 확인 |
| LOCAL-05 | 성능 비교 | 입력·출력 토큰 조건을 고정하고 동시성 1·2·4에서 각각 100건 결과 저장 |
| LOCAL-06 | 로컬 데이터 처리 | 외부 추론 API 사용 없이 응답, 프롬프트·응답 본문의 기본 로그 저장 비활성화 |
| LOCAL-07 | 운영 확인 | 준비 상태·GPU 메모리·요청 실패율 확인, 모델 로딩 실패 시 원인 확인 가능 |

## 품질 기준

- 기능 검증과 모델 답변 품질 평가 분리: API 성공만으로 한국어·코딩 품질 충족 판정 금지
- 정상 부하 완료 조건: 선정한 지원 동시성에서 요청 실패와 OOM 0건
- 부하 증가 중 실패 발생 시 지원 동시성 하향 또는 설정 수정 후 재측정
- 기록 지표: 첫 토큰 지연 p50/p95, 전체 지연 p50/p95, 출력 tokens/s, 실패율, 최대 VRAM
- 절대 지연 목표: GPU·모델 및 최초 측정 결과 확인 후 결정
- 초기 모델 다운로드에 인터넷 사용 허용; 완전 폐쇄망 배포는 별도 요구 확인
- 자격증명·가중치·로컬 결과물의 Git 추적 제외

## 추적 관계와 미결 사항

- 설계·단계별 일정: [RFC-0001](../rfcs/RFC-0001-local-vllm.md)
- 구현 후 갱신 대상: Architecture, API Spec, Operations 및 테스트
- GPU: 3090 1개 확인, 실제 VRAM·드라이버·가용 메모리는 실행 환경에서 확인 필요
- 우선 용도: 한국어 대화·코딩 확인; 목표 동시 사용자·입력 길이는 미정
- 모델명·revision·라이선스·정밀도: 환경 확인 후 선정
