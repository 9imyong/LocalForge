# 변경 제안서 안내

RFC는 아직 방향이 정해지지 않았고 여러 대안 또는 관계자의 검토가 필요한 큰 변경에 사용합니다. 이미 방향이 정해진 구현은 작업 문서로, 확정된 중요한 결정은 ADR로 기록합니다.

파일 이름은 `RFC-0001-짧은-제목.md` 형식을 사용합니다.

## 작성 기준과 결과

- 여러 대안, 팀 또는 시스템을 함께 검토해야 할 때 작성합니다.
- 방향이 이미 정해진 국소 변경에는 작성하지 않습니다.
- 승인 결과가 장기간 보존할 중요한 아키텍처 결정이면 ADR을 추가합니다.
- 단순 구현 승인이라면 ADR 없이 Task로 연결할 수 있습니다.

전체 흐름과 생략 기준은 [문서 운영 정책](../DOCS_GOVERNANCE.md)을 따릅니다.
