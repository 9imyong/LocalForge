# C4 System Context

## 문서 목적

시스템과 사용자, 외부 시스템의 관계를 한눈에 보여줍니다. 관계의 상세 의미는 [시스템 맥락](../../context.md)에 기록합니다.

## 언제 수정하는가

시스템 경계, 주요 사용자 또는 외부 시스템 관계가 바뀔 때 수정합니다.

## 작성할 내용

- 관심 대상 시스템 하나
- 주요 사용자와 외부 시스템
- 방향과 목적이 드러나는 관계 이름

## 최소 예제

```mermaid
flowchart LR
    사용자[사람: 주요 사용자]
    시스템[소프트웨어 시스템: 대상 시스템]
    외부[소프트웨어 시스템: 외부 서비스]
    사용자 -->|기능을 사용한다| 시스템
    시스템 -->|필요한 처리를 요청한다| 외부
```
