# 시스템 맥락

## 문서 목적

시스템이 해결하는 문제와 책임 경계, 주요 사용자와 외부 시스템을 설명합니다. 상세 인터페이스 계약은 다루지 않습니다.

## 언제 수정하는가

- 시스템의 책임 범위 또는 주요 사용자가 달라질 때
- 새로운 외부 시스템을 연동하거나 기존 연동을 제거할 때
- 외부와 주고받는 정보의 목적이 바뀔 때

## 작성할 내용

- 해결하는 문제와 책임 범위
- 주요 사용자 및 외부 시스템
- 상호작용의 목적과 주고받는 정보
- 명시적인 범위 밖 항목

## 최소 예제

| 대상 | 관계 | 주고받는 정보 |
|---|---|---|
| 주요 사용자 | 시스템 기능 사용 | 요청과 처리 결과 |
| 외부 서비스 | 부가 기능 제공 | 식별자와 처리 상태 |

프로젝트의 정식 시각화는 [C4 System Context](diagrams/c4/context.md)에 작성하고, 이 문서에는 관계의 의미를 기록합니다.

## 범위 밖 항목

- 이 시스템이 책임지지 않는 영역을 작성합니다.
