# 해결 전략

## 문서 목적

핵심 품질 목표와 제약을 만족하기 위한 상위 수준의 기술·구조적 접근을 요약합니다. 세부 구성 요소나 결정 이력을 반복하지 않습니다.

## 언제 수정하는가

- 시스템의 핵심 품질 목표나 주요 제약이 달라질 때
- 전체 구조, 통합 방식 또는 데이터 전략이 크게 바뀔 때
- 새로운 ADR이 기존 전략을 대체할 때

## 작성할 내용

- 가장 중요한 품질 목표
- 선택한 구조 및 통합 방식의 요약
- 데이터와 배포에 대한 핵심 접근
- 전략을 뒷받침하는 ADR 링크

## 최소 예제

> 변경 빈도가 높은 사용자 접점과 안정적인 업무 규칙을 분리하고, 구성 요소 사이에는 명시적인 계약을 사용한다.
